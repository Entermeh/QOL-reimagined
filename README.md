## ✨ Features

- **⚡ 30+ High-Impact Optimizers**: Hardware GPU Scheduling (HAGS), Game Mode, Win32 Gaming Priority (0x26), Low-Latency Network Tweaks, SSD TRIM, Cache Purging, and more.
- **📦 48+ One-Click Performance Apps**: BleachBit, Geek Uninstaller, Revo Uninstaller, HWiNFO, MSI Afterburner, Everything Search, Process Explorer, and more installed via visual Winget console.
- **🎮 8 Built-in Retro Games**: Reaction Speed Tester, Rock Paper Scissors Lizard Spock, Higher or Lower, Simon Memory, Number Guess, Coin Toss, Roll Dice, and RNG Rush.
- **🎨 28 Curated Color Themes**: Dark modes, Cyberpunk, Nord, Matrix, Solarized, and more with instant live preview.
- **🪶 Ultra-Lightweight**: Native Win32 working set trimmer purges RAM to **<10 MB** with **0.0% idle CPU**.
